# Texite 官网功能演示

七段演示各自可播放。滚动至对应介绍，设备内切换相关功能面板；点击播放后由可见鼠标驱动真实组件。点击工作区或输入可接手并停止播放。每次播放前自动备份当前示例，不重置用户文稿。

| 场景 | 操作顺序 | 最后让用户看见什么 |
| --- | --- | --- |
| 01 编辑操作 | Code 选中标题并输入 → Visual 改写正文 → 切回 Code → 编译 | 两种模式编辑同一源码；右侧显示带明确说明的模拟 PDF |
| 02 右键与行内 AI | 正文右键 → 表格设置为两行两列、勾选三线表并插入 → 再次右键 → 搜索并插入 α → 拖动选中结果段落 → 输入 AI 要求并发送 | 表格与符号写入源码；预设 AI 只修改选区，并展示预设回答 |
| 03 项目搜索 | 打开项目搜索 → 打开文件范围 → 清除选择、只勾选 main.tex → 搜索 synthetic → 点击结果 | 编辑器跳转到对应行；方框和标签标注落点 |
| 04 快捷引用 | 在正文准备引用位置并点击光标 → 打开参考文献 → 搜索 Lamport → 点击插入引用 | `\\cite{latex1994}` 出现在之前的光标位置 |
| 05 历史与备份 | 创建项目备份、填写备注 → 修改标题 → 打开修改历史 → 查看增删 → 预览恢复 → 保留当前版本并恢复 → 还原项目备份 | 单文件历史和整项目备份的作用得到分别展示 |
| 06 AI 助手 | 打开 Agent → 发送修改要求 → 查看差异 → 撤回修改 → 切到对话 → 发送问题 | Agent 能修改且可撤回；对话回答问题而不改文稿 |

| 07 设置 | 外观与主题 → 界面字号 → 编辑器文字与字体 → 编译设置 → 同步与存储 → 关于 → 返回文稿 | 五个选项卡的位置与用途；不改偏好、不连接服务、不删除数据 |

## 演示节奏

- 先用字幕说明目的，再移动鼠标；鼠标落下后有点击反馈。
- Code 输入逐字写入；选择正文时逐步扩展选区。
- 菜单、差异窗口和定位结果处停留，避免只闪一下。
- 定位方框只作为演示标注，不修改产品本身的 UI。
- 支持系统“减少动态效果”偏好，仍保留步骤说明和结果停留。

## 预设与保护

AI 修改与回答均预设，不联网、不调用模型。行内修改校验 UTF-16 选区，只改指定的示例段落；未知自定义内容不自动覆盖。Agent 同样只处理已知示例段落。对话只返回预设说明，不调用修改工具。

编译沿用模拟 PDF：面板持续显示“网页未加载编译器，结果为模拟演示”。模拟结果不保证与任意自定义源码一致。
