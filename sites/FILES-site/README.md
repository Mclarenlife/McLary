# FILES-site

Mosby’s Files 的本地交互复刻，采用原生 HTML / CSS / JavaScript，无运行时框架依赖。

## 启动

在本目录运行：

```powershell
node server.mjs
```

打开 http://localhost:4173 。也支持 `npm run dev` 或 `pnpm dev`。启动网站不需要安装依赖；Node.js 20+ 即可。

## 已实现

- 首页四组彩色档案：每份文件夹分为带标签的固定背板与独立前盖；悬浮标签时前盖轻微翻开，下方堆叠跟随倾斜、分类展开与收起、保留展开状态。
- 十五个学习档案的独立路径 `/cases/<slug>`，可直接打开和刷新。
- 点击标签后其他文件夹依次向下移出画面，首页标题与说明向上裁切淡出；选中的文件夹独立留在画面中，再整体转动 90° 并沿左侧书脊翻开；同组切换先合上旧封面，停留，再翻开新档案。
- 返回首页反向旋转归档并恢复位置与焦点；支持浏览器前进 / 后退、Esc 关闭档案。滚动到末尾后继续滚动，色块向上展开成下一份文件夹；色块中的名称以更大的位移上移、放大为页标题，纸张延迟出现。
- 纸张纹理、装订孔、回形针、照片与便签拼贴、滚动入场及照片放大。
- About 页面、移动端布局、键盘焦点、减少动画偏好支持。
- 32 张本地 AVIF 素材、本地 Anton 字体，浏览时无需访问外部资源。

## 验证与构建

```powershell
pnpm install
pnpm test
pnpm build
```

`dist/` 是静态产物，包含首页、About 和十五个详情路径的目录入口。服务器需要支持目录索引。

测试覆盖：档案路由和图片完整性、展开状态恢复、标签切换、键盘操作、快速连续点击、历史状态恢复。测试运行于 Happy DOM，不等同于真实浏览器渲染测试。

## 主要文件

- `src/data.js`：建筑师、分类、作品介绍。
- `src/views.js`：页面结构。
- `src/app.js`：路由、展开切换、连续滚动、照片对话框。
- `src/motion.js` / `src/motion.css`：可取消的分阶段翻合、90° 旋转、逐字标题动画。
- `src/styles.css`：首页和通用样式。
- `src/details.css`：档案拼贴、About 和响应式样式。
- `assets/`：本地图片和字体。

这是根据公开页面内容和官方展示图重新实现的版本，并非原站源码镜像。保留了核心视觉和档案交互；介绍文字经过重写，摄影、色彩与建筑详情使用拼贴模板，赛车集合使用独立驾驶笔记版式，没有逐页复刻原站的全部长篇内容、音视频和独立装饰物。文件夹动画根据用户提供的 2026-10-02 录屏逐段分析，并在浏览器访问恢复后直接核对原站。时长集中在 `src/motion.js` 的 `TIMING` 中。

已在真实桌面浏览器中核对打开、同组切换、返回归档的中间帧，并检查控制台。28 项 DOM 测试覆盖状态恢复、快速点击、遮挡完成前不替换文档，中途返回时的动画清理、首页下移退场、完整主体遮挡、标签收放与横竖坐标交接、稳定悬浮命中、各标签独立的双层封面及前盖翻开状态点击，顶栏返回时文件夹与文字错峰弹入，同排标签及底板弹入，底部按首页行集合循环跳转，以及色块／标题独立转场。移动触控尚未做真机验证。

图片来自原站公开的 Storyblok 资源，设计与图片权利归原作者及相应权利人。字体 Anton 按 SIL Open Font License 使用，许可证见 `assets/Anton-OFL.txt`。

横竖标签共用一套轮廓与尺寸规则；旋转时按起止位置、字号和内边距连续插值，避免临时标签替换产生跳变。

第一行是摄影学习集合：相机使用基础、构图基础。内容位于 src/lessons.js，每份包含三个章节及实操练习，使用 assets/camera-*.svg 与 assets/composition-*.svg 原创示意图。旧路由保留，避免已有链接失效。

第二行是色彩知识集合：色彩基础（沿用 frank-gehry 路由）、色彩关系（color-relationships）、配色实践（color-palette）。内容位于 src/color-lessons.js，每份包含三个章节、练习与四张示意图；图稿可由 scripts/create-color-art.py 重新生成。

色彩知识新增专业进阶：对比与互补（color-contrast）、颜色叠加（color-blending），每份四章，图稿生成于 scripts/create-advanced-color-art.py。后者含 sRGB 编码通道、全不透明底层的交互混合实验，覆盖正常、正片叠底、滤色及叠加，算法参考 W3C Compositing and Blending Level 1。课程末附参考链接。当前共 15 个文件夹、17 个页面入口；五标签行已作紧凑排版。

首页文件夹组填满视口底部，桌面主体达到 820px 后不再随窗口增高，而是整组向下移动；阈值由 `src/motion.css` 的 `--archive-height-limit` 调整（含顶部 48px 标签空间，默认 868px）。短窗口和展开说明较多时允许自然滚动，不裁切内容。顶栏始终使用页面全部宽度。打开和返回动画分别测量首页背板的真实宽高，旋转交接保持矩形尺寸，并补偿标签比例，避免切换成正方形引起高度突变。

旋转阶段只移动闭合的彩色封面；封面到位后直接揭开原始文档，不再用缩放的文档副本替换正文。返回时先在原位置收回真实标签并合盖，再旋转归档；同排其他文件夹的标签和底板按原有层级错峰弹出。侧边标签沿用首页横排字形，整体转向侧边，不将中文切换为逐字竖排。同组标签及下一集合文档均使用页面原节点，保留集合尺寸变量和滚动定位。


第三行是赛车技巧集合：驾驶与抓地、刹车与走线、弯道与出弯、练习与复盘，共 20 章。前三份沿用 louis-kahn、i-m-pei、paul-rudolph 路径，新增 race-practice。内容位于 `src/racing-lessons.js`；独立排版位于 `src/racing-view.js` 与 `src/racing.css`，包含章节目录、工程师便签、折叠诊断、练习卡、复盘清单及可放大的原创图稿。8 张 SVG 可通过 `node scripts/create-racing-art.mjs` 重新生成。

驾驶与抓地包含交互抓地圆：用归一化理想圆展示横向与纵向需求的关系，并非真实轮胎曲线或踏板输入建议。所有练习以模拟赛车或有教练指导的封闭赛道为背景，各课程末附 Driver61 与 iRacing 延伸阅读。章节锚点保持当前文档，仅滚动定位。已检查桌面长文侧栏、390px 窄屏排版、图片放大及交互数值。


第四行是飞行驾驶技巧：操纵与姿态、起飞与着陆、导航与气象、仪表与决策，共 16 节。前两份沿用 mary-colter、louis-sullivan 路径，后两份为 flight-navigation、flight-instruments。独立内容、模板与样式分别位于 `src/flight-lessons.js`、`src/flight-view.js`、`src/flight.css`；9 张原创 SVG 可运行 `node scripts/create-flight-art.mjs` 生成。版式含航务简报条、章节目录、教员便签、模拟练习、折叠问答与飞行复盘页。

导航档案提供风分量实验：使用固定风速和相对来风方向，计算顺逆风及左右侧风分量，并展示吹去方向的矢量。它不是偏流修正、飞机性能或起降许可计算器。课程以固定翼原理、地面知识和模拟练习为主，引用 FAA 手册及稳定进近资料，具体机型与真实操作仍须依据适用手册和训练。测试覆盖四档案切换、集合循环、图稿放大及风分量的逆风、顺风、左右侧风与静风边界。


色彩集合已扩写为五份、每份五章，共 25 章。`src/color-notes.js` 为原有内容补充应用分析、常见误区和新章节；原课程与图稿继续复用。新增内容涵盖 HSL 与感知差异、中性色倾向、颜色节奏、深浅色适配、配色交接、WCAG 文字对比与合成结果排查。独立模板和样式位于 `src/color-view.js`、`src/color-notebook.css`，含章节导航、便签、折叠答疑、练习记录和五个配色案例；保留颜色叠加实验。每个案例给出色值、用途、可视对照和三步练习，文末附 W3C 资料。已验证五档案切换、章节定位、图稿与案例、混合实验，以及桌面和窄屏排版。

## GitHub Pages 子路径部署

运行 `node scripts/build.mjs --base=/files/`，将 `dist/` 的内容发布到 Pages 仓库的 `files/`。首页、About 和档案详情均有静态目录入口，支持直接访问与刷新。本地开发仍使用根路径；部署前运行 `node --test tests/*.test.mjs`。
